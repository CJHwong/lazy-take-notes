# Keys

Press `h` in a session to see the keys of that screen.

## Recording

| Key | Action |
|---|---|
| `Space` | Pause or resume |
| `s` | Stop recording |
| `d` | Update the notes now |
| `m` | Mute or unmute the mic |
| `1` to `5` | Run a quick action of the template |
| `c` | Copy the panel that has the focus |
| `Tab`, `shift+tab` | Move the focus: transcript, speaker bar, notes, session context |
| `l` | Rename the session |
| `o` | Open the session folder, after the recording stops |
| `h` | Show or hide the help |
| `q` | Quit after the final notes |
| `ctrl+q` | Save the audio and quit now, without the final notes |

## Transcribing a file

The same keys as a recording, except `Space` and `m`. `s` stops the transcription.

## Viewing a saved session

| Key | Action |
|---|---|
| `c` | Copy the panel that has the focus |
| `o` | Open the session folder |
| `Tab`, `shift+tab` | Move the focus: transcript, speaker bar, notes |
| `q` | Back to the session list |

## Speaker bar

The speaker bar is under the transcript once a speaker is found. These keys work while it has the focus. They are in the native build only; in the Python version, click a chip.

| Key | Action |
|---|---|
| `←`, `→` | Choose a speaker. Their lines are highlighted |
| `Enter` | Name the chosen speaker |
| `Esc` | Clear the choice |
